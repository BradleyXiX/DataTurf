# AI Assistant Instructions for DataTurf

**Project Goal:** DataTurf is a sports statistics aggregator showcasing advanced frontend solution development. 

**Engineering Priorities:**
*   Prioritize highly polished, responsive frontend solutions.
*   Focus on efficient state management, graceful degradation (skeleton loaders), and clean data visualization.
*   Keep Next.js server/client boundaries strict.

**Tech Stack:**
*   **Frontend:** Next.js (App Router), React, Tailwind CSS.
*   **Data Visualization:** Recharts (or similar charting library).
*   **Backend / API:** Node.js, Express, PostgreSQL.
*   **Data Ingestion:** Python, Playwright, AWS Lambda, EventBridge.

**Coding Style:**
*   Write modular, reusable React components.
*   Use standard error handling for API fetches.
*   Ensure all data tables and charts are mobile-responsive.
