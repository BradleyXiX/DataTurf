# Contributing to DataTurf

First off, thank you for considering contributing to DataTurf! It's people like you that make DataTurf such a great tool for sports analytics.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check the Issues section of the repository to see if someone else has already created a ticket. If not, go ahead and make one!

## Development Setup

To set up the project locally, please refer to the `Quick Start` section in the [README.md](README.md). You will need:
- Node.js
- PostgreSQL
- Python (for data ingestion)

## Code Style

- **Frontend**: We use Next.js (App Router), React, and Tailwind CSS. Ensure components are modular and responsive.
- **Backend**: We use Express.js. Keep routes clean and modular.
- **Linting**: Please follow standard Javascript style conventions.

## Submitting a Pull Request

1. Fork the repository.
2. Create a new branch (`git checkout -b feature/your-feature-name`).
3. Make your changes and commit them (`git commit -m "Add some feature"`).
4. Push to the branch (`git push origin feature/your-feature-name`).
5. Open a Pull Request.

Thank you for contributing!
